# assets/

Static files served next to `index.html`.

- **resume.pdf** — your compiled resume. The "Resume" button links to `assets/resume.pdf`.
  Drop your PDF here with exactly this name (or change the href in index.html).
- **favicon.svg** — the browser-tab icon, referenced from index.html.
- **images** — put project screenshots or photos here and reference them
  in index.html as `assets/your-image.png`.
